ThroughFocus_Viewer v2.0.0 — Windows standalone
====================================================

No Python install required / 不需安裝 Python。

Run: run_ThroughFocus_Viewer.bat  or  ThroughFocus_Viewer.exe

If DLL errors occur on a clean PC, install Microsoft Visual C++
Redistributable (x64) from Microsoft.
若出現 DLL 錯誤，請安裝 Microsoft Visual C++ Redistributable (x64)。

Optional Sample\ folder next to the exe opens as default Group.
可選：exe 旁 Sample\ 作為無參數預設圖集。

Help: ThroughFocus_Viewer_Help.html (F1)
