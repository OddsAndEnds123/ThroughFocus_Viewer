ThroughFocus_Viewer

Through-focus image ROI viewer. Display and measurement only — no wavefront reconstruction algorithms.
通焦影像 ROI 檢視器。僅顯示與量測——不含波前重建演算法。

This public Help covers Usage and Architecture only. It does not embed demo images or historical release notes.
本公開說明僅含用法與架構；不嵌入示範圖、不含歷史版本紀錄。

Usage / 用法

ThroughFocus_Viewer opens through-focus image stacks, draws ROIs, builds a Focus×Radial intensity preview, and exports Result / profile / preview data. Start with run_throughfocus_viewer.bat [image|folder|*.bmp …]. With no arguments the app opens its configured default folder (one Group).
ThroughFocus_Viewer 可開啟通焦影像疊圖、繪製 ROI、建立 Focus×Radial 強度預覽，並匯出 Result／剖面／預覽資料。啟動：run_throughfocus_viewer.bat [影像|資料夾|*.bmp …]。無參數時開啟設定的預設資料夾（一個 Group／圖集）。

Architecture / 函式架構

Module layers for the viewer package (display name ThroughFocus_Viewer). Reconstruction algorithms are out of scope.
viewer 套件模組分層（顯示名稱 ThroughFocus_Viewer）。重建演算法不在範圍內。

Shell / 協調層 GUI Core / 核心庫 Boundary / 邊界

Open images / 開啟影像

  • File → Open Image(s)…（可多選）、拖放檔案／資料夾，或 bat／命令列傳路徑。
  • File → Open Folder…（Ctrl+Shift+O）：由資料夾建立一個 Group／圖集（標籤＝資料夾名；只掃一層）。
  • Formats / 格式：PNG／BMP／TIFF／JPEG。Folders are not scanned recursively / 資料夾不遞迴。
  • Loose files that share the same field and through-focus step/dz naming merge into one Group; others stay single-frame.
    同一 Field 且通焦 step/dz 命名相近的散檔會合成一個 Group；其餘為單張。

Layout / 版面

  • Top-left / 左上：Auto／Manual、Analyze、X_Pixel、Y_Pixel、Z_Step、共用 Unit（µm／nm），主圖 Preview：False Color／Edge（互斥，僅顯示）。
  • Left / 左側：中央影像＋通焦步階滑桿；下方 ROI 參數、Result 表、Log。
  • Right / 右側：Groups／圖集與 Through-Focus／通焦預覽（Focus×Radial；預設 False Color；Mode＝Contour／False Color）。
  • Multi-frame thumbnails use stacked-card cue (×N) / 多幀縮圖以疊層卡片示意。
  • Splitters and window geometry are restored / 分割與視窗幾何會記住。
  • Status bar / 狀態列：路徑、待命進度、Log 開關、游標 XY。

Through-focus preview / 通焦預覽（Analyze）

  • Auto：ROI 或尺度參數變更後自動更新。
  • Manual：按 Analyze 才重建。
  • False Color（預設）：turbo 強度圖。Contour：灰階底圖＋等值線。
  • Snap to focus centroid／對齊合焦質心：新建／拖曳結束／Analyze 時，將 ROI 中心對齊近零焦幀強度質心。
  • Focus axis / Focus 軸：檔名有 dz 則用之（換算到目前 Unit）；否則用 Z_Step。
  • Radial axis / Radial 軸：ROI 沿 u 剖面 × 像素尺度（含旋轉與 X／Y_Pixel）。

ROI and export / ROI 與匯出

  • Draw mode 拖曳建立 ROI；Fixed size；Snap to focus centroid；CX／CY／W／H／Angle；Delete；Rotate 90°（R）。
  • ROI_Rota：向心指引；統一旋轉；或 None／關閉。
  • ROIs are shared across focus steps in the same Group / 同一圖集內 ROI 跨步階共用；換步階只換顯示幀。
  • Result columns / Result 欄位：ROI_ID、CX、CY、W、H、Rota_Angle、ColorSpace、Max、Min、CalcTime、FolderName（無 MTF）。
  • Save／Load ROI Settings（Ctrl+S／Ctrl+Shift+S）：CSV；儲存不覆寫。
  • Normalize（預設開）：通焦強度峰值歸一。
  • Preview Aspect：Fixed Window／Physical。Axes 開／關。紅色 Focus 步階標線。Focus 刻度四等分。
  • Save preview / 另存預覽：右鍵或 Save Image；預設名 [Folder]_ROIX_Real|Pixel。
  • Export Excel：Result／ROI_*／TF_ROI_*；單一檔或分檔；不覆寫。
